Entry for the [news-image-20261124 bounty](https://make.fun/bounty/news-image-20261124)
on make.fun.

## How it works

`main.ts` copies `entry.png` (1024×1024, 50 stories) to the output directory.
It runs twice and writes the same bytes both times.

`build_image.py` draws the front page from scratch with PIL: masthead, a
generated editorial illustration of the burning tankers in the Strait of
Hormuz, four lead headlines, a 45-story grid with accurate small flags, and
the markets footer.
